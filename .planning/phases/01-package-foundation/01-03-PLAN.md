<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Claude hook stdin -> local hook handler | Hook JSON payloads may be malformed or contain sensitive prompt/tool data. |
| hook handler -> stdout/stderr | Hook messages may be surfaced to users, logs, or agent context. |
| hook adapter files -> package code | Adapter refactor can break blocking behavior if imports or exits are wrong. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-03-01 | Information Disclosure | `privguard.hooks.main_user_prompt` | mitigate | Use `format_hit_summary` and `redact`; never print `Hit.value` or original prompt text. |
| T-01-03-02 | Information Disclosure | `privguard.hooks.main_pre_tool` | mitigate | Emit reason codes only; do not include raw `.env`, `data_sensivel/**`, raw command snippets, or inline PII in stderr. |
| T-01-03-03 | Tampering | `hooks/pii_guard.py`, `hooks/pre_tool_guard.py` | mitigate | Keep entry files and exit behavior stable; adapters call package handlers and use `raise SystemExit(...)`. |
| T-01-03-04 | Denial of Service | malformed hook JSON | mitigate | Preserve fail-open malformed JSON handling with `return 0` for `json.JSONDecodeError` and `ValueError`. |
| T-01-03-05 | Elevation of Privilege | blocking semantics | mitigate | Preserve exit code `2` on blocked prompt/tool violations. |
</threat_model>
