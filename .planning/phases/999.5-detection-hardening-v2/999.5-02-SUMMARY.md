# Phase 999.5 Plan 02: Detection PATTERNS Fixes Summary

Four targeted regex/constant edits to `privguard/detection.py` to close BR_CEP dot-variant, CNPJ leniency, spaced-IBAN false-positive, and BR_BOLETO barcode suppression gaps.

## What Was Built

Four edits to `privguard/detection.py` with zero new functions or imports:

1. **BR_CEP regex extended** — `\b(?:\d{2}\.\d{3}|\d{5})-?\d{3}\b` now covers `NN.NNN-NNN` dot-variant alongside the original `NNNNN-NNN` and bare `NNNNNNNN` formats.

2. **Spaced-IBAN PatternEntry added** — `\b[A-Z]{2}\d{2}(?:\s[A-Z0-9]{4}){3,}(?:\s[A-Z0-9]{1,4})?\b` with `{3,}` minimum-3-groups quantifier. Same kind `IBAN`, same score `0.90`. The full IBAN span wins over the inner `BR_PHONE` span via the existing overlap sort.

3. **BR_BOLETO PatternEntry added** — Three-format alternation covering raw `\b\d{44,50}\b`, FEBRABAN human-readable, and hyphen-check printed format. Score `0.92` beats `BR_PIS_PASEP` (0.91) and `BR_PHONE` (0.76) via existing overlap sort.

4. **_LENIENT_KINDS and _LENIENT_SCORES extended** — Both constants now include `"BR_CNPJ"` with score `0.75`. The existing formatted-only guard (`"." in value and "-" in value`) in the detect() leniency block covers CNPJ correctly without change: formatted `XX.XXX.XXX/XXXX-XX` has both `.` and `-`; bare `XXXXXXXXXXXXXX` has neither (D-03 satisfied).

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Extended raw boleto digit range from {44,47} to {44,50}**
- **Found during:** Task 1, GREEN phase
- **Issue:** Plan's `<action>` specifies `\b\d{44,47}\b` but the plan's own `<verification>` script uses a 50-digit raw barcode string `83660000000004960019073330190105042231239010103400`. The regex with `{44,47}` does not match 50 digits; the verification fixture would fail.
- **Fix:** Changed quantifier to `{44,50}`. Brazilian utility boletos (concessionárias: water, power, telecoms) can be 44-48 digits; allowing up to 50 provides a safe margin while keeping the pattern bounded.
- **Files modified:** `privguard/detection.py` (line 178)
- **Commit:** `4614cd3`
