# Phase 999.5 Plan 01: Name Data Files and Package-Data Infrastructure Summary

**One-liner:** Static IBGE name data files (57 first names, 25 surnames) added to `privguard/data/` with `pyproject.toml` package-data declaration enabling `importlib.resources.files()` access at runtime.

## What Was Built

Two UTF-8 plain text name data files were created in `privguard/data/`:

- `names_first.txt` — 57 lowercase Brazilian first names: IBGE 2010 Census top-20 female, top-20 male, and 17 additional common names
- `names_surnames.txt` — 25 lowercase Brazilian surnames from public-domain sources

`pyproject.toml` was updated with a `[tool.setuptools.package-data]` section (`privguard = ["data/*"]`) immediately after the existing `[tool.setuptools.packages.find]` block so the data files are included in the installed package.

After the change, `pip install -e .` was re-run and `importlib.resources.files("privguard") / "data" / "names_first.txt"` was verified to resolve without error.
