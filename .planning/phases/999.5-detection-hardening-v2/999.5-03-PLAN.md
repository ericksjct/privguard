**Step 4 — Add `_find_name_hits()` function after `_detect_names_default()` and before `_LENIENT_KINDS`**

CRITICAL: The function is named `_find_name_hits` (NOT `detect_names`) to avoid shadowing the `detect_names` parameter in `detect()`.

```python
def _find_name_hits(text: str) -> list[Hit]:
    first_names, surnames = _load_name_sets()
    tokens: list[tuple[str, int, int]] = [
        (m.group(0).lower(), m.start(), m.end())
        for m in _TOKEN_RE.finditer(text)
    ]
    hits: list[Hit] = []
    i = 0
    while i < len(tokens):
        tok, ts, te = tokens[i]
        is_first = tok in first_names
        is_surn = tok in surnames
        # first-name + adjacent surname → full name (0.72)
        if is_first and i + 1 < len(tokens):
            ntok, nts, nte = tokens[i + 1]
            if ntok in surnames:
                hits.append(Hit("BR_NAME", ts, nte, text[ts:nte], 0.72, "name_fullname"))
                i += 2
                continue
        # surname-first + adjacent first-name → full name (0.72)
        if is_surn and i + 1 < len(tokens):
            ntok, nts, nte = tokens[i + 1]
            if ntok in first_names:
                hits.append(Hit("BR_NAME", ts, nte, text[ts:nte], 0.72, "name_fullname"))
                i += 2
                continue
        if is_first:
            hits.append(Hit("BR_NAME", ts, te, text[ts:te], 0.58, "name_first"))
        elif is_surn:
            hits.append(Hit("BR_NAME", ts, te, text[ts:te], 0.65, "name_surname"))
        i += 1
    return hits

```

|-----------|----------|-----------|-------------|-----------------|
| T-999.5-03-01 | Information Disclosure | BR_NAME hits leaking into logs | mitigate | Name hits use score 0.58-0.72; they pass through the same output hygiene layer as all other hits. The masking layer replaces values with `<BR_NAME>`. Detection itself only emits kind/score/offsets in non-mask paths |
| T-999.5-03-02 | Tampering | _TOKEN_RE ReDoS | mitigate | `[^\W\d_]+` is a simple character class with no nested quantifiers; linear time. The `re.UNICODE` flag does not affect worst-case complexity |
| T-999.5-03-03 | Denial of Service | Large name data files causing slow import | accept | lru_cache(maxsize=1) ensures file I/O runs once per process. Files are ~50KB max. Loading is O(n) over file lines, bounded by committed file size |
| T-999.5-03-04 | Tampering | False positive name masking suppressing legitimate content | accept | Name detection is opt-in (D-07); user must explicitly pass --detect-names or set PII_GUARD_DETECT_NAMES=true. Default behavior is unchanged |
| T-999.5-03-05 | Tampering | Parameter name collision detect_names shadowing function | mitigate | Function explicitly named _find_name_hits() per W-1 warning in PATTERNS.md. Unit test in Plan 04 will catch any regression |
