**Opt-in lenient CPF detection (PII_GUARD_LENIENT env var or lenient=True param) masks formatted DDD.DDD.DDD-DD strings with invalid checksums, scoring 0.75 with reason_code='lenient_pattern', while strict mode remains the default**

## Files Created/Modified

## Decisions Made

- Lenient mode scoped to formatted CPF only (`DDD.DDD.DDD-DD`); bare 11-digit CPF stays strict to preserve BR_CNH and BR_PIS_PASEP on overlapping spans
- `None` default for `lenient` parameter defers to `_lenient_default()` env-var read; explicit `True`/`False` overrides
- `verify_mask()` intentionally not passed `lenient` — verification remains strict as defense-in-depth layer
- Score `0.75` for lenient hits (vs `0.95` strict) ensures strict hits always win in overlap resolution
