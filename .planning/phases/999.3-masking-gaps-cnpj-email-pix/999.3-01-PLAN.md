## Objective

Corrigir 3 bugs de regex em `privguard/detection.py` encontrados no stress test `texto_com_pii.txt`:
1. **RG sufixo obrigatório** — evita capturar prefixo de CNPJ como RG
2. **BR_PHONE sem `\b`** — permite detectar `+55XX...` sem espaço entre código de país e DDD
3. **BR_PLACA_OLD lookahead** — evita capturar IDs de transação como placa

## Context

- **Arquivo principal:** `privguard/detection.py` linhas 167–192 (lista `PATTERNS`)
- **Script de diagnóstico:** `scripts/test_gaps.py` (confirma todos os 3 bugs)
- **Nota sobre emails:** emails são detectados corretamente — o garbling no stress test era encoding do PowerShell (CP1252 vs UTF-8), não um bug de detecção.

## Evidence (scripts/test_gaps.py)

```
cnpj-full     12.345.678/0001-90 -> [('BR_RG', 0.78)]   # deveria ser BR_CNPJ ou nada
phone-+55-nospace  +5516988887777 -> NO HIT              # deveria ser BR_PHONE
txn-id        TXN-2026-0315-887766 -> [('BR_PLACA_OLD')] # falso positivo
```

<action>

PatternEntry("BR_RG", re.compile(r"\b\d{1,2}\.\d{3}\.\d{3}(?:-[\dXx])?\b"), 0.78),

<task id="2">
<name>Fix 2: BR_PHONE — remover \b antes do DDD</name>

<read_first>
- privguard/detection.py (após task 1)
</read_first>

<action>
Localizar a linha do BR_PHONE em `PATTERNS` (aprox. linha 178):

```python
PatternEntry("BR_PHONE", re.compile(r"(?:\+55\s?)?\(?\b\d{2}\)?\s?(?:9\d{4}|[2-5]\d{3})-?\d{4}\b"), 0.76),
```

Substituir por:

```python
PatternEntry("BR_PHONE", re.compile(r"(?:\+55\s?)?\(?\d{2}\)?\s?(?:9\d{4}|[2-5]\d{3})-?\d{4}\b"), 0.76),
```

Mudança: remover `\b` antes de `\d{2}` (o DDD). O `\b` impede o match quando `+55` está colado ao DDD sem espaço, pois entre `55` e `16` não há word boundary.
</action>

<acceptance_criteria>
- `privguard/detection.py` contém `r"(?:\+55\s?)?\(?\d{2}\)?\s?(?:9\d{4}|[2-5]\d{3})-?\d{4}\b"` (sem `\b` antes do DDD)
- `uv run python scripts/test_gaps.py` mostra `phone-+55-nospace -> [('BR_PHONE', 0.76)]`
- `uv run python scripts/test_gaps.py` mostra `phone-+55-space -> [('BR_PHONE', 0.76)]` (não regrediu)
</acceptance_criteria>
</task>

<task id="3">
<name>Fix 3: BR_PLACA_OLD — adicionar negative lookahead (?![-\d])</name>

<read_first>
- privguard/detection.py (após task 2)
</read_first>

<action>
Localizar a linha do BR_PLACA_OLD em `PATTERNS` (aprox. linha 181):

```python
PatternEntry("BR_PLACA_OLD", re.compile(r"\b[A-Z]{3}-?\d{4}\b"), 0.80),
```

Substituir por:

```python
PatternEntry("BR_PLACA_OLD", re.compile(r"\b[A-Z]{3}-?\d{4}(?![-\d])\b"), 0.80),
```

Mudança: adicionar `(?![-\d])` após os 4 dígitos. O lookahead negativo impede match quando os 4 dígitos são seguidos de `-` ou outro dígito — o que ocorre em IDs de transação como `TXN-2026-0315` mas não em placas reais como `ABC-1234` ou `ABC1234`.
</action>

<acceptance_criteria>
- `privguard/detection.py` contém `r"\b[A-Z]{3}-?\d{4}(?![-\d])\b"`
- `uv run python scripts/test_gaps.py` mostra `txn-id -> NO HIT`
- `uv run python scripts/test_gaps.py` mostra `placa-real -> [('BR_PLACA_OLD', 0.8)]`
</acceptance_criteria>
</task>

def test_rg_does_not_match_cnpj_prefix() -> None:
    """RG pattern must not capture the XX.XXX.XXX prefix of a CNPJ."""
    from privguard.detection import detect
    hits = detect("12.345.678/0001-90")
    kinds = [h.kind for h in hits]
    assert "BR_RG" not in kinds, "CNPJ prefix must not be classified as RG"


def test_rg_still_detected_with_suffix() -> None:
    """RG with explicit digit suffix must still be detected."""
    from privguard.detection import detect
    hits = detect("12.345.678-9 SSP/SP")
    kinds = [h.kind for h in hits]
    assert "BR_RG" in kinds


def test_phone_detected_without_space_after_country_code() -> None:
    """+55XX format without space between country code and DDD must be detected."""
    from privguard.detection import detect
    hits = detect("+5516988887777")
    kinds = [h.kind for h in hits]
    assert "BR_PHONE" in kinds, "+55DDD9XXXXXXXX must be detected as BR_PHONE"


def test_transaction_id_not_classified_as_plate() -> None:
    """Transaction IDs like TXN-2026-0315 must not be classified as BR_PLACA_OLD."""
    from privguard.detection import detect
    hits = detect("TXN-2026-0315-887766")
    kinds = [h.kind for h in hits]
    assert "BR_PLACA_OLD" not in kinds, "Transaction ID must not be classified as license plate"


def test_real_plate_still_detected() -> None:
    """Real BR license plates must still be detected after lookahead fix."""
    from privguard.detection import detect
    hits = detect("placa ABC-1234 do veiculo")
    kinds = [h.kind for h in hits]
    assert "BR_PLACA_OLD" in kinds
