          return _run_fail_closed(_main_user_prompt_impl, event="UserPromptSubmit")

      def main_pre_tool() -> int:

  where:

      def _run_fail_closed(impl, *, event: str) -> int:
          try:
              return impl()
          except Exception:
              _audit_log(event=event, action="block", reason_code="detector_error")
              sys.stderr.write(
                  f"[PII-GUARD BLOQUEADO] reason=detector_error action=block event={event} "
                  "remediation=detector_failed_blocking_by_default\n"
              )
              return 2

  Catch `Exception` only (NOT BaseException) so KeyboardInterrupt/SystemExit still propagate.
  The public names must stay `main_user_prompt` / `main_pre_tool` (console-script entry points
  and __init__ re-exports depend on them). Do not leak any exception text/PII into stderr — the
  message is a fixed sanitized string.
