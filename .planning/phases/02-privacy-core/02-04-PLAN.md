## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| shell/stdin -> CLI | Untrusted text enters local scan/mask/policy commands. |
| CLI -> stdout/stderr | Output may be copied to tools, terminals, or tests and must be sanitized except explicit masked payload output. |
| package exports -> future adapters | Stable APIs will be consumed by Phase 3 and Phase 4 without integration-specific assumptions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04-01 | Information Disclosure | `privguard scan` | mitigate | Route output through sanitized diagnostics only. |
| T-02-04-02 | Information Disclosure | `privguard mask` | mitigate | Print masked payload only for explicit mask command and verify it before success status. |
| T-02-04-03 | Spoofing | `policy-check --capability` | mitigate | Validate capability labels against D-09 constants and default unknown/external to fail-closed. |
| T-02-04-04 | Repudiation | CLI exit/status | mitigate | Return deterministic exit codes and reason-code diagnostics for allow/block/pause decisions. |
</threat_model>
