<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller -> detection core | Untrusted prompt/tool/path-like text enters local detector memory. |
| detection core -> diagnostics/masking | Raw hit values must remain internal and only sanitized metadata may cross to diagnostics. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01-01 | Information Disclosure | `Hit.value` and tests | mitigate | Keep raw values inside detection/masking only; tests assert summaries do not expose `value`. |
| T-02-01-02 | Tampering | checksum validators | mitigate | Port validators from the existing demo reference and add invalid-lookalike regression tests. |
| T-02-01-03 | Denial of Service | regex detector | mitigate | Keep regexes bounded, deterministic, and test overlap handling on synthetic input. |
| T-02-01-04 | Spoofing | optional Presidio parity | mitigate | Make package validators canonical so optional adapters cannot drift silently. |
</threat_model>
