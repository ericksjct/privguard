## Formato JSON Line

```json
{"ts": "2026-05-21T19:30:00.123456Z", "event": "PreToolUse", "action": "block", "reason_code": "inline_pii", "category": "llm_orchestration"}
```

Campos:
- `ts`: `datetime.datetime.utcnow().isoformat() + "Z"` — ISO 8601 UTC
- `event`: `"UserPromptSubmit"` | `"PreToolUse"`
- `action`: `"block"` | `"warn"`
- `reason_code`: passado por quem chama (ex: `"pii_detected"`, `"unknown_tool"`)
- `category`: passado quando disponível (string vazia se não houver)

## Localização do Log

```python
import pathlib
LOG_PATH = pathlib.Path.home() / ".privguard" / "audit.log"
```

`Path.home()` em Windows retorna `C:\Users\<username>` — confiável em Python 3.8+.

Criação do diretório: `log_dir.mkdir(parents=True, exist_ok=True)` — idempotente, não levanta exceção se já existir.

## Implementação Fire-and-Forget

```python
def _audit_log(*, event: str, action: str, reason_code: str, category: str = "") -> None:
    try:
        import datetime, json, pathlib
        log_dir = pathlib.Path.home() / ".privguard"
        log_dir.mkdir(parents=True, exist_ok=True)
        entry = {"ts": datetime.datetime.utcnow().isoformat() + "Z",
                 "event": event, "action": action,
                 "reason_code": reason_code, "category": category}
        with (log_dir / "audit.log").open("a", encoding="utf-8") as f:
            f.write(json.dumps(entry) + "\n")
    except Exception:
        pass  # never fail the hook
```

Imports dentro do try: evita qualquer falha de import afetando o hook.
`open(..., "a")`: append atômico em arquivos pequenos no mesmo processo — suficiente para MVP.

## Padrão de Teste (de test_claude_hooks.py)

Testes existentes usam:
- `monkeypatch.setattr(sys, "stdin", io.StringIO(payload))`
- `run_pre_tool(monkeypatch, payload)` helper
- `capsys` para capturar stderr

Para testar `_audit_log()`:
1. `monkeypatch.setattr(pathlib, "Path", ...)` — substituir `Path.home()` por `tmp_path`
2. Alternativa mais limpa: passar `log_path: pathlib.Path | None = None` como parâmetro opcional a `_audit_log()` — em produção usa o default, em teste recebe `tmp_path / "audit.log"`.

A segunda abordagem (parâmetro `log_path`) é preferível: não precisa monkeypatch de Path, sem side-effects globais.
