| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-08-01 | Information Disclosure | mask branch stderr output | mitigate | Only write `mask_result.text` to stderr after `mask_result.verified` is True. The `if not mask_result.verified: return 2` gate prevents unverified (potentially PII-containing) text from reaching stderr. |
| T-08-02 | Elevation of Privilege | mask mode exit code | mitigate | mask mode MUST always exit 2 (block). No code path in mask mode may exit 0 when PII is detected. Verified by acceptance criteria: both mask branch paths return 2. |
