## Recommendations

1. **Add scheme validation** (fixes C1 and C3): add `if parsed.scheme not in {"https", "http"}:` (or just `{"https"}`) before the netloc check. Blocks ftp://, file://, // (protocol-relative), javascript:, etc.
2. **Use `parsed.hostname` instead of `parsed.netloc`** (fixes C2): `parsed.hostname` strips port numbers and userinfo, giving just the lowercased host. Replace `netloc = parsed.netloc.lower()` with `netloc = parsed.hostname or ""`.
3. **Add `_audit_log` for allowed WebFetch** (fixes C5): after `return 0`, add `_audit_log(event="PreToolUse", action="allow", reason_code="webfetch_allowlisted", category="webfetch", url_domain=netloc)`. Or log inside `check_webfetch` before returning True.
4. **Fix stale comment** (fixes C6): update line 304 comment to reflect that WebFetch is now domain-gated, not fully blocked.
5. **Consider subdomain depth limit** (C4): document the conscious trust decision, or restrict to exact matches only for high-risk domains. At minimum, add a comment noting that user-controlled subdomain hosting on any allowlisted domain would be implicitly trusted.
