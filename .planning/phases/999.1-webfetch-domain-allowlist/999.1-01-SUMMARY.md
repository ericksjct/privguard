# Phase 999.1 Plan 01: WebFetch Domain Allowlist Summary

**One-liner:** WebFetch domain allowlist via `_ALLOWED_FETCH_DOMAINS` frozenset and `check_webfetch()` using `urlparse().netloc` canonical extraction with subdomain matching.

## What Was Built

Replaced the blanket `unknown_tool` block for WebFetch with targeted domain-based allowlist gating in `privguard/hooks.py`. Claude Code can now fetch documentation from 7 trusted public domains while all other external network egress remains blocked.

## Implementation Details

### _ALLOWED_FETCH_DOMAINS (frozenset, 7 domains)

```
github.com, raw.githubusercontent.com, docs.python.org, pypi.org,
docs.anthropic.com, docs.rs, crates.io
```

### check_webfetch() behavior

- `{"url": "https://github.com/foo"}` → `(True, "")` — exact match
- `{"url": "https://api.github.com/foo"}` → `(True, "")` — subdomain match
- `{"url": "https://evil.com/foo"}` → `(False, "webfetch_domain_not_allowed")` — blocked
- `{"url": "https://notgithub.com/foo"}` → `(False, "webfetch_domain_not_allowed")` — not a subdomain
- `{"url": "https://evil.com/github.com/repo"}` → `(False, "webfetch_domain_not_allowed")` — path bypass blocked
- `{}` → `(False, "webfetch_url_missing")` — missing key
- `{"url": ""}` → `(False, "webfetch_url_missing")` — empty string
- `{"url": "evil.com/path"}` → `(False, "webfetch_domain_not_allowed")` — no scheme, netloc=""

### main_pre_tool() WebFetch branch

Placed immediately after `tool_input` normalization and BEFORE `_is_allowed_tool()`:

```python
if tool == "WebFetch":
    ok, reason_code = check_webfetch(tool_input)
    if not ok:
        return _deny_pre_tool(reason_code=reason_code, category="webfetch")
    return 0
```
