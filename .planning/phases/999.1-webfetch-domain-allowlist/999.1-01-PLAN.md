```python
def check_webfetch(tool_input: dict) -> tuple[bool, str]:
    """Allow WebFetch only to domains in _ALLOWED_FETCH_DOMAINS.

    Subdomain matching: a netloc of "api.github.com" is allowed because it
    ends with ".github.com" (i.e. the parent domain "github.com" is allowed).
    """
    url = tool_input.get("url") or ""
    if not url or not isinstance(url, str):
        return False, "webfetch_url_missing"
    parsed = urlparse(url)
    netloc = parsed.netloc.lower()
    if not netloc:
        return False, "webfetch_domain_not_allowed"
    # Exact match or subdomain match (netloc ends with ".<allowed_domain>")
    for domain in _ALLOWED_FETCH_DOMAINS:
        if netloc == domain or netloc.endswith("." + domain):
            return True, ""
    return False, "webfetch_domain_not_allowed"
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Claude Code -> hooks.py | WebFetch tool_input arrives as JSON; URL field is untrusted |
| hooks.py -> external network | Domain allowlist is the gate; any approved domain still reaches the network |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-999.1-01 | Spoofing | check_webfetch URL parsing | mitigate | Use urlparse().netloc for canonical domain extraction; never do substring match on raw URL string (e.g. "evil.com/github.com" would bypass naive string search) |
| T-999.1-02 | Tampering | _ALLOWED_FETCH_DOMAINS | accept | Constant is defined in source code; modification requires a code change and code review |
| T-999.1-03 | Information Disclosure | WebFetch response contents | accept | privguard does not inspect response bodies; WebFetch is a read-only operation to public docs |
| T-999.1-04 | Elevation of Privilege | Subdomain bypass via crafted URL | mitigate | Subdomain check uses ".endswith('.' + domain)" not plain "in url" — "notgithub.com" does not match "github.com"; netloc must equal domain or end with ".domain" |
| T-999.1-05 | Denial of Service | Allowlist misconfiguration | accept | Fail-closed by default: unknown domains are blocked; misconfiguration causes over-blocking, not under-blocking |
</threat_model>
