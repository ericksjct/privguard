# Codebase Structure

**Analysis Date:** 2026-05-01

## Directory Layout

```text
microsoft-presidio/

│   └── codebase/            # Architecture/structure mapping documents
```

## Directory Purposes

**Repository Root:**
- Purpose: Holds standalone executable demo scripts.
- Contains: `test_presidio.py`, `test_presidio_br.py`, `reversible_demo.py`, and `ollama_local_demo.py`.
- Key files: `test_presidio_br.py` is the main reusable Presidio module because `reversible_demo.py` imports `build_br_recognizers()` from it.

**`.claude/`:**
- Purpose: Configures Claude Code permissions and hooks for this workspace.
- Contains: `.claude/settings.json` and `.claude/settings.local.json`.
- Key files: `.claude/settings.json` wires `hooks/pii_guard.py` to `UserPromptSubmit` and `hooks/pre_tool_guard.py` to `PreToolUse`.
- Guidance: Read `.claude/settings.json` for architecture mapping. Treat `.claude/settings.local.json` as local machine configuration unless a task explicitly requires it.

**`.planning/`:**
- Purpose: Stores GSD planning artifacts.
- Contains: `.planning/codebase/`.
- Key files: `.planning/codebase/ARCHITECTURE.md`, `.planning/codebase/STRUCTURE.md`.
- Guidance: Codebase mapping agents may update files in `.planning/codebase/` only when requested.

**`data_sensivel/`:**
- Purpose: Stores sensitive local data files.
- Contains: `data_sensivel/cooperados.csv` and `data_sensivel/dump_2025_05.txt`.
- Key files: Do not read or quote contents from files in `data_sensivel/`.
- Guidance: Use only path-level knowledge. Access is denied by `.claude/settings.json` and guarded by `hooks/pre_tool_guard.py`.

**`hooks/`:**
- Purpose: Contains Claude Code runtime policy hooks for prompt and tool-use protection.
- Contains: `hooks/_pii_core.py`, `hooks/pii_guard.py`, `hooks/pre_tool_guard.py`, and generated `hooks/__pycache__/`.
- Key files: `hooks/_pii_core.py` is shared by both executable hooks.
- Guidance: Keep hook dependencies standard-library-only to preserve low startup latency and avoid requiring Presidio in the hook path.

**`__pycache__/` and `hooks/__pycache__/`:**
- Purpose: Python-generated bytecode caches.
- Contains: `.pyc` files generated by Python execution.
- Key files: Not applicable.
- Guidance: Do not add source logic here.

## Key File Locations

**Entry Points:**
- `test_presidio.py`: English/default Presidio analyzer and anonymizer demo.
- `test_presidio_br.py`: Portuguese/Brazilian Presidio recognizer demo and reusable recognizer factory.
- `reversible_demo.py`: Local reversible anonymization flow using Presidio encrypt/decrypt operators.
- `ollama_local_demo.py`: Local Ollama availability check and localhost generation demo.
- `hooks/pii_guard.py`: Claude `UserPromptSubmit` hook entry point.
- `hooks/pre_tool_guard.py`: Claude `PreToolUse` hook entry point.
- `hooks/_pii_core.py`: Standalone scanner smoke-test entry point when executed directly.

**Configuration:**
- `.claude/settings.json`: Claude Code deny rules and hook command wiring.
- `.env`: Local environment configuration file exists; do not read contents.

**Core Logic:**
- `test_presidio_br.py`: Brazilian identifier validators, `ChecksumPatternRecognizer`, Presidio recognizer construction, Presidio operator construction.
- `hooks/_pii_core.py`: Lightweight regex/validator detection and redaction core for hooks.
- `hooks/pre_tool_guard.py`: Sensitive path, shell-read, exfiltration, and inline PII policy checks.
- `hooks/pii_guard.py`: Prompt-level block/warn/scrub behavior.

**Sensitive Data:**
- `data_sensivel/cooperados.csv`: Sensitive local CSV; path only.
- `data_sensivel/dump_2025_05.txt`: Sensitive local text dump; path only.

**Testing:**
- No dedicated test framework or test directory is present.
- `test_presidio.py` and `test_presidio_br.py` are executable demos despite their `test_*.py` names.

## Naming Conventions

**Files:**
- Root demos use descriptive snake_case names ending in `.py`: `test_presidio_br.py`, `reversible_demo.py`, `ollama_local_demo.py`.
- Hook modules use snake_case names in `hooks/`: `_pii_core.py`, `pii_guard.py`, `pre_tool_guard.py`.
- Generated bytecode uses Python cache naming in `__pycache__/`.

**Directories:**
- Sensitive data is isolated in a Portuguese snake_case directory: `data_sensivel/`.
- Hook scripts live in `hooks/`.
- Planning docs live in `.planning/codebase/`.

**Functions and Classes:**
- Python functions use snake_case: `build_analyzer()`, `build_br_recognizers()`, `valida_cpf()`, `has_ollama_server()`, `check_bash()`.
- Brazilian validation functions use Portuguese verb naming: `valida_cpf()`, `valida_cnpj()`, `valida_pis()`.
- Classes use PascalCase: `ChecksumPatternRecognizer`, `Hit`.
- Constants use uppercase: `SAMPLES`, `PATTERNS`, `THRESHOLD`, `MODE`, `OLLAMA_HOST`, `SENSITIVE_GLOBS`.

## Where to Add New Code

**New Presidio Demo:**
- Primary code: Add a new root-level script such as `new_demo.py` if it is a standalone runnable demo.
- Shared recognizers: Add reusable Brazilian recognizer changes to `test_presidio_br.py` if they are Presidio-based.
- Hook-independent reusable logic: Prefer a new root-level module only if more than one demo imports it.

**New Brazilian Entity Recognizer:**
- Primary code: Add validator logic and `PatternRecognizer` or `ChecksumPatternRecognizer` construction in `test_presidio_br.py`.
- Registration: Add the recognizer to the list returned by `build_br_recognizers()`.
- Operators: Add anonymization behavior to `build_operators()` in `test_presidio_br.py`.
- Hook coverage: Add a separate lightweight regex pattern to `hooks/_pii_core.py` if Claude prompt/tool guarding must detect the same entity without loading Presidio.

**New Claude Prompt Guard Behavior:**
- Primary code: `hooks/pii_guard.py`.
- Shared scanner behavior: `hooks/_pii_core.py`.
- Hook wiring: `.claude/settings.json`.
- Rule: Keep stdout JSON-compatible for allowed hook context output and use stderr with exit code `2` for blocks.

**New Claude Tool Guard Behavior:**
- Primary code: `hooks/pre_tool_guard.py`.
- Sensitive path patterns: `SENSITIVE_GLOBS` in `hooks/pre_tool_guard.py`.
- Command detection: `READ_CMDS`, `EXFIL_CMDS`, or `check_bash()` in `hooks/pre_tool_guard.py`.
- Shared PII/secret signatures: `PATTERNS` in `hooks/_pii_core.py`.

**New Local LLM Demo:**
- Primary code: Add or extend `ollama_local_demo.py` for Ollama-specific behavior.
- Network boundary: Keep local-only calls pointed at `127.0.0.1` unless the task explicitly changes the trust boundary.

**New Sensitive Data Files:**
- Location: `data_sensivel/`.
- Guard updates: Add matching deny rules to `.claude/settings.json` and `SENSITIVE_GLOBS` in `hooks/pre_tool_guard.py`.
- Documentation: Mention paths only; do not include file contents in docs.

**Utilities:**
- Hook utilities: Add to `hooks/_pii_core.py` when required by both hook entry points.
- Presidio utilities: Keep in `test_presidio_br.py` while the codebase remains script-oriented; extract to a dedicated module only when multiple root scripts need the same non-demo functionality.
